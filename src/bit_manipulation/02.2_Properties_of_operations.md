# 📜 Properties of Bitwise Operations

## 1. Idempotent Law

* **AND**

  ```text
  a & a = a
  ```

* **OR**

  ```text
  a | a = a
  ```

* **XOR**

  ```text
  a ^ a = 0
  ```

  XOR does **not** satisfy the idempotent law because the result is `0`, not `a`.

💬 *"When something already exists, applying it again doesn't change it. But XOR removes itself when doubled."*

---

## 2. Commutative Law

* **AND**

  ```text
  a & b = b & a
  ```

* **OR**

  ```text
  a | b = b | a
  ```

* **XOR**

  ```text
  a ^ b = b ^ a
  ```

💬 *"The order doesn't matter; the result stays the same."*

---

## 3. Associative Law

* **AND**

  ```text
  (a & b) & c = a & (b & c)
  ```

* **OR**

  ```text
  (a | b) | c = a | (b | c)
  ```

* **XOR**

  ```text
  (a ^ b) ^ c = a ^ (b ^ c)
  ```

💬 *"Changing the grouping doesn't change the outcome."*

---

## 4. Distributive Law

### AND over OR

```text
a & (b | c) = (a & b) | (a & c)
```

### OR over AND

```text
a | (b & c) = (a | b) & (a | c)
```

### AND over XOR

```text
a & (b ^ c) = (a & b) ^ (a & c)
```

### XOR over AND

```text
a ^ (b & c) = (a ^ b) & (a ^ c)
```

💬 *"Some operations can be distributed across others while preserving the result."*

---

## 5. De Morgan’s Laws

### NOT of AND

```text
~(a & b) = ~a | ~b
```

### NOT of OR

```text
~(a | b) = ~a & ~b
```

💬 *"Negating AND turns it into OR, and negating OR turns it into AND."*

---

## 6. Negative Number Properties (Two's Complement)

### Negative One

```text
-1 = ~0
```

### Negating a Number

```text
-a = ~(a - 1)
```

Equivalent form:

```text
-a = (~a) + 1
```

💬 *"Invert all bits and add one to obtain the negative representation."*

---

## 7. AND Operation Properties

### AND with Zero

```text
a & 0 = 0
```

### AND with All Ones

```text
a & (-1) = a
```

### AND with Its Complement

```text
a & ~a = 0
```

💬 *"AND with zero erases everything, while AND with all ones changes nothing."*

---

## 8. OR Operation Properties

### OR with Zero

```text
a | 0 = a
```

### OR with Its Complement

```text
a | ~a = -1
```

💬 *"OR with your complement produces all ones."*

---

## 9. XOR Operation Properties

### XOR with Zero

```text
a ^ 0 = a
```

### XOR with Itself

```text
a ^ a = 0
```

### XOR with All Ones

```text
a ^ (-1) = ~a
```

### Self-Inverse Property

If:

```text
a ^ b = c
```

Then:

```text
c ^ b = a

c ^ a = b
```

💬 *"XOR is reversible. Apply the same value again and the effect is undone."*

---

## 10. Important Bit Manipulation Tricks

### Remove the Rightmost Set Bit

```text
a & (a - 1)
```

Removes the least significant (rightmost) set bit.

#### Example

```text
a      = 10010000
a - 1  = 10001111

a & (a - 1)
       = 10000000
```

💬 *"The rightmost set bit disappears."*

---

### Isolate the Rightmost Set Bit

```text
a & (-a)
```

Keeps only the least significant set bit.

#### Example

```text
a      = 10010000
-a     = 01110000

a & -a = 00010000
```

💬 *"Everything disappears except the rightmost set bit."*

---

### Check if a Number is a Power of Two

A positive number is a power of two if:

```text
a > 0
```

and

```text
(a & (a - 1)) == 0
```

#### Examples

```text
8 = 1000

1000 & 0111 = 0000 ✓
```

```text
16 = 10000

10000 & 01111 = 00000 ✓
```

```text
10 = 1010

1010 & 1001 = 1000 ✗
```

💬 *"A power of two contains exactly one set bit."*

---

### Check if a Number is Even or Odd

#### Even

```text
(a & 1) == 0
```

#### Odd

```text
(a & 1) == 1
```

#### Examples

```text
10 = 1010

1010 & 0001 = 0
```

```text
11 = 1011

1011 & 0001 = 1
```

💬 *"The least significant bit tells whether a number is even or odd."*

---

### Count Set Bits (Brian Kernighan's Algorithm)

Repeatedly perform:

```text
a = a & (a - 1)
```

until:

```text
a = 0
```

Each operation removes one set bit.

#### Example

```text
a = 13

1101
1100
1000
0000
```

Number of operations = 3

Therefore:

```text
13 contains 3 set bits.
```

💬 *"Remove one set bit at a time until none remain."*

---

## 11. Shift Operator Properties

### Left Shift

```text
a << n = a * (2^n)
```

#### Example

```text
5 << 1 = 10
5 << 2 = 20
```

---

### Right Shift

```text
a >> n = floor(a / (2^n))
```

#### Example

```text
20 >> 1 = 10
20 >> 2 = 5
```

💬 *"Left shift multiplies by powers of two; right shift divides by powers of two."*

---

## 12. Useful Identity Summary

```text
a & a       = a
a | a       = a
a ^ a       = 0

a & 0       = 0
a | 0       = a
a ^ 0       = a

a & (-1)    = a
a | ~a      = -1
a & ~a      = 0

-a          = (~a) + 1

a & (a - 1) -> Remove rightmost set bit
a & (-a)    -> Isolate rightmost set bit

(a & 1)     -> Check odd/even

(a & (a - 1)) == 0
             -> Power of two
```

---

## Why These Matter

These identities are heavily used in:

* Bit Masking
* Competitive Programming
* Dynamic Programming with Bitmasks
* Fenwick Trees (Binary Indexed Trees)
* Segment Trees
* Graph Algorithms
* Low-Level System Programming
* Optimized Mathematical Computations

Mastering these properties turns many complex problems into elegant one-line solutions.
